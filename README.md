# BAIL504 — Data Visualization Lab

This repository is the shared download location for the BAIL504 Data Visualization Lab programs.

## Goal

Each completed lab should be saved in its native desktop-project format so classmates can open the same workbook/report and inspect the same visual output:

- **Tableau:** packaged workbook (`.twbx`) with its data extract or required local data included.
- **Power BI:** report (`.pbix`) with its imported data and model included.

## Important dataset note

The supplied PDF is a lab manual, not a dataset bundle. It describes the datasets and exercises, but the actual CSV/XLS/XLSX source files are not attached to the manual PDF. To make the packaged workbooks reproducible and ensure classmates see the same results, add the **exact classroom datasets** used by your lab to the matching program folders before treating a program as complete. Do not silently substitute similarly named public datasets.

Each program folder should contain:
1. The native final project (`.twbx` for Tableau or `.pbix` for Power BI).
2. The exact source dataset(s), where redistribution is permitted and needed.
3. A short `README.md` with opening instructions and any required software/version notes.
4. An output screenshot (`.png`) as a quick preview.

## Opening the projects

- Download a Tableau `.twbx` file and open it in Tableau Desktop.
- Download a Power BI `.pbix` file and open it in Power BI Desktop.
- Keep any separately supplied source data in the folder structure described by that program's README.

## Completion status

The repository currently contains datasets and their provenance notes. Native `.twbx` and `.pbix` workbooks and checked output screenshots have **not** yet been created. They must be authored and verified in Tableau Desktop and Power BI Desktop; this repository does not claim that a CSV or README is a completed native report.
